# Demo 2: Backlog refinement with AI

Prompt:

```
Let's work through backlog refinement for the system. I will explain features and bug fixes that are required for the system, and I want you to ask clarifying questions and read the codebase to understand any implementation details that would be needed by a developer picking up this issue. Once enough information is gathered create an issue in GitHub for this work. Only ask questions if needed. The issues should have "just enough information" needed to be picked up for work.
Before we start, though, what would be a good GitHub issue format for our backlog? These issues should be readable by humans, but also have enough detail so an AI agent could potentially pick up the issue and complete it on its own.
```
